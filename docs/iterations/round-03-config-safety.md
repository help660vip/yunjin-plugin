# 第 3 轮：配置读取安全性

## 更新内容

- 配置读取只接受已注册且符合模式的持久化值，坏值不会覆盖默认配置。
- 保留配置校验对坏值和未知键的诊断能力，方便管理员修复配置文件。
- 修复全局、群、群组、用户中文作用域别名。
- 修复敏感配置脱敏提示，统一显示为“[已隐藏]”。
- 增加配置回归测试，覆盖坏值隔离、中文作用域和敏感值隐藏。

## 边界行为

- 配置文件中的无效值不会被静默写回，“#云锦配置 校验”仍会报告具体问题。
- 未注册配置键不会进入有效配置视图。
- 敏感键只返回脱敏文本，不在消息中暴露原始值。

## 风险与取舍

- 依赖旧版错误配置运行的能力会回退到模式默认值，管理员需要根据校验结果修正原配置。
- 作用域别名仅影响解析，不改变存储键和权限边界。
