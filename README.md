# YunJin Plugin · 云锦

面向 TRSS-Yunzai 与 Miao-Yunzai 的模块化群聊综合助手。

## 安装

将本目录放入 Yunzai 的 `plugins/yunjin-plugin`，然后重启机器人。运行数据默认写入宿主根目录下的 `data/yunjin-plugin`，不会写入插件源码目录。

## 当前能力

### 配置中心

配置中心支持全局、群组和用户三级作用域。优先级为：默认值 < 全局覆盖 < 群组覆盖 < 用户覆盖。

| 命令 | 用途 | 权限 |
| --- | --- | --- |
| `#云锦 配置 查看` | 查看当前作用域的有效配置 | 已登录用户 |
| `#云锦 配置 获取 <作用域> <键>` | 获取一个配置键 | 已登录用户 |
| `#云锦 配置 设置 <作用域> <键> <JSON值>` | 设置配置键 | 全局主人、群管理员、本人 |
| `#云锦 配置 重载` | 从磁盘重新载入配置 | 主人或群管理员 |
| `#云锦 配置 校验` | 检查配置文件和注册 Schema | 主人或群管理员 |

作用域使用 `全局`、`群`、`用户`，也接受 `global`、`group`、`user`。敏感字段不会在聊天中回显，未知键和非法值会被拒绝。

## 运行与兼容性

插件使用 JavaScript ESM。TRSS-Yunzai 与 Miao-Yunzai 的主机能力通过运行时探测适配，缺少可选 Bot API、Redis 或渲染器时会安全降级为文本输出。

## 数据与隐私

配置数据只写入宿主的数据目录。日志和审计记录默认脱敏，不记录 token、Cookie、密码或完整用户消息。请勿把真实密钥提交到仓库。
